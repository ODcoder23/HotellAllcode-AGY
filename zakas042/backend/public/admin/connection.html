Ulash

Beds24 → Settings → Marketplace → API: invite code yarating. Ruxsatlar: bookings (o'qish + yozish, shaxsiy va moliyaviy), inventory (o'qish + yozish), properties (o'qish). Kod bir martalik; invite code allaqachon ishlatilgan bo'lsa — Beds24'dagi refresh token. Kalit bazada shifrlangan saqlanadi va hech qachon ko'rsatilmaydi. Ulangandan keyin xonalarni bog'lang — shundan keyin Beds24 bronlari import qilinadi.
